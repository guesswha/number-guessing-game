# Number Guessing Game

A simple number guessing game written in Python.

## Features

- Randomly generates a number from 1 to 100.
- Three difficulty levels:
  > Easy
  > Medium
  > Hard
- Gives hints after each incorrect guess.
- Handles invalid input.
- Allows the player to play again after each game.

## Requirements

- Python 3.x

## How to Run

1. Clone the repository:

git clone https://github.com/guessswha/number-guessing-game.git

2. Open the project folder.

3. Run:

python numberguessinggame.py
